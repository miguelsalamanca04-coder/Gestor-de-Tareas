Electiva - PWA · UPTC

Qué es esto
-----------
El Gestor de Tareas con IndexedDB y Web Crypto API ya integrados
(Sesión 22). La persistencia dejó de ser localStorage (texto plano,
síncrono) y pasa por una base de datos IndexedDB real: object store
"tareas" con clave autoincremental e índices por prioridad y por
título. Cada tarea puede llevar, además, una nota privada: se cifra
con AES-GCM usando una clave derivada por contraseña con PBKDF2 (no
una clave aleatoria de un solo uso) — la contraseña nunca se guarda,
solo se usa en el momento para re-derivar la misma clave cada vez.
Es el punto de partida de la Sesión 23 (Workbox y auditoría): el
Service Worker sigue siendo el mismo de la Sesión 21, sin cambios.

Cómo probarlo
--------------
  1. VS Code + extensión "Live Server": clic derecho sobre index.html →
     "Open with Live Server".
  2. Terminal, parado en esta carpeta:
       python3 -m http.server 8080
     y abrir http://localhost:8080 en el navegador.
  3. Agrega una tarea, escribe algo en "Nota privada" y pulsa
     "🔒 Guardar" — la primera vez pedirá una contraseña (cualquiera,
     la que quieras probar). Pulsa "👁 Ver nota" para descifrarla.
     Recarga la página: la tarea y la nota siguen ahí (IndexedDB), y
     volver a escribir la MISMA contraseña vuelve a descifrarla bien.
  4. Para ver los datos en crudo: DevTools → Application → IndexedDB →
     gestor-tareas-db → tareas. El campo notaCifrada debe verse como
     bytes ilegibles, nunca como el texto original.
